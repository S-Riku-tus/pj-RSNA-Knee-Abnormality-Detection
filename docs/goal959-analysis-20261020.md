## 今回の結果をどう見るか

## 捨てた案と、そこから分かったこと

教師JEVの順位は既存の弱ラベルに非常によく一致したが、重症度の基準と確率の大きさは一致していなかった。固定画像特徴量・同じridge分類器で、その違いを分けた。

| 固定weak fold0の比較 | 固定10所見の平均AUC |
| --- | ---: |
| A：従来の二値教師・元の観測mask | 0.837830 |
| B：JEVの確率へ置換・同じ観測mask | 0.825155 |
| C：JEVの有限な確率へ教師範囲を拡張 | 0.832982 |
| D：Cの確率を学習側の観測教師だけで単調補正 | 0.835253 |

教師範囲の拡張と確率補正は損失の一部を回復したが、Aを超えなかった。事前の採用基準を満たさず、追加fold・画像モデル学習・正式提出へ進めない。これは小さな固定特徴量の比較であり、Publicスコアの推定ではない。自分のGoldは使っていない。JEVの上流Gold選択履歴は別に開示している。

## 現在進めている検証

R6について、公開trainerのUIDハッシュfold規則とmanifestの一致を確認した。各検査をその除外foldの重みだけで予測し、TTAの重み0/0.25/0.5と既存後処理の有無を、同じ画像予測から比較する。

2つの弱ラベル検証集団は809件・855件。全4,407検査のレポートgroupと既存の供給groupを結合し、R6のfoldをまたぐgroupを除外した。Kaggleへ渡すのはUIDと分割情報だけで、ラベルとReportは渡さない。人工GPU確認を通してから実MRIを処理する。実行・成功率98%以上・対応する予測の一致を確認した後に、両集団で固定10所見の平均AUC差がともに正となる変更を選ぶ。bootstrapは不確実性の報告に用い、後から採用基準を動かさない。

公開重みの実際の学習集団を独立に証明できたわけではない。補助事前学習と上流Gold選択履歴も残るため、完全に独立した全パイプラインのOOFや患者独立性は主張しない。P033全体の検証ではなく、R6の変更を選ぶための限定された根拠である。

別の一要因として、同じ重みの入力中心切り出しを352から320へ狭める比較も開始した。関節への集中が役立つ可能性と、周辺の所見を落とす可能性の両方がある。元の3候補と合わせた4候補のうち、両検証で成功した同じ検査に対して、両bankでの差が正となるものを選ぶ。両bankのうち小さい改善幅が最大の1案を優先し、R6からの正式提出は合計1案までとする。この全体方針も、予測の解析前に固定した。crop320とTTA変更などを組み合わせた案は評価しない。

過去のF009は学習中のAMP更新スキップ1回で、当時の厳しい実行基準を満たさずHOLDだった。別の問いとして、固定E12で対照と候補の更新機会・実更新・スキップが同じか確認し、予測品質を探索的に分析した。両方のfold1が同じ2495更新・2496機会・E10 skip1で、gamma候補はfold0で+0.001693、fold1で+0.000902の固定10平均AUC差となった。ただしfold1の95%区間は[−0.000298,+0.002114]でゼロを含む。旧HOLDを取り消したり、旧consumerの採用条件を緩めたりはしない。別scopeでのCPU確認では、固定E12の全suffix/headが有限で、元と完全一致する厳密な復元、人工392px encoder/head入力・12出力が両foldとも通過した。CUDA/実MRI・固定融合との結合は未完で、これもPublic改善の証明ではない。

## 残り2枠の使い方

1. P045が0.959以上なら、本人の公式結果と保存版を照合して目標達成を記録する。
2. R6の両集団で改善する変更があれば、元bestへ一要因だけ反映し、今回の実出力・契約を確認して手動提出する。
3. P045が0.958の場合に限り、DINO比率20%のP046を別の探索候補にする。0.957以下なら20%は棄却する。P046には独立したDINOのOOF根拠がなく、検証済み改善とは呼ばない。準備はsourceだけで、Save・実画像・正式提出は未実施である。
