# 実験記録

## 仮説と変更

実験ID、比較元、変更する一要因、期待する結果を記入する。

## 再現条件

Git commit、config、seed、fold、manifest hash、ラベルのURLと版、重みのURLと版、GPU、ライブラリの版を記入する。

## 結果

weak検証BCE、goldの12項目別AUCと陽性数、定義できないクラス、Public LB、採点日時、Notebook版、起動・デコードを含む推論時間を記入する。

## 検証の独立性

goldに合わせたラベル調整の有無、公開重みの学習対象、同一患者・レポート・施設の漏洩確認、検証に使ったラベルの由来を記入する。

## 判断

採用・保留・不採用の理由、速度と精度の交換条件、次に確認する失敗例を記入する。小標本の微差だけで採用を決めない。
